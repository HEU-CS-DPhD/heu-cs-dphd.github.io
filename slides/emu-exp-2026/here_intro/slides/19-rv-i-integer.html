◈ 模块二：后端执行扩展 —— 基础整数指令集 (RV32I & RV64I)

精确复现 RISC-V 基础规范：符号拓展、截断运算与分支跳转
❖ 算术、位移与分支跳转核心运算
  • 算术与逻辑运算：ADD/SUB/AND/OR/XOR/SLL/SRL/SRA 及立即数版本，统一通过 ExecTrait 泛型模板纯函数计算。
  • 64 位特有截断指令 (*W 后缀)：ADDW/SUBW/SLLW/SRAW 对低 32 位运算后强制执行 64 位符号拓展 (Sign-Extension)。
  • 分支与无条件跳转：BEQ/BNE/BLT/BGE/BLTU/BGEU 比较条件分支；JAL/JALR 寄存器链接跳转与 PC 对齐校验。
  • 高位立即数寻址：LUI 与 AUIPC 高 20 位立即数构造与 PC 相对寻址。
❖ 内存访存加载与存储 (Load / Store)符号与零扩展
统一通过泛型处理 1/2/4/8 字节访存与符号拓展： 
pub(super) fn handle_load<T, const EXTEND: bool>(
    cpu: &mut RVCPU, rd: u8, addr: WordType,
) -> Result<(), Exception> where T: UnsignedInteger {
    let data = cpu.read::<T>(addr)?;
    let mut data = (data.into(): u64) as WordType;
    if EXTEND {
        data = sign_extend(data, size_of::<T>() * 8);
    }
    cpu.reg_file.write(rd, data);
    Ok(())
}
支持 LB/LBU (1B), LH/LHU (2B), LW/LWU (4B), LD (8B) 及 SB/SH/SW/SD。
