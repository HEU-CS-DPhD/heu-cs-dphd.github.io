◈ 核心亮点四：双轨调试系统 —— 原生交互式 rvdb 与 GDB RSP

兼具轻量内省与工业生态：自研 ELF 符号解析 REPL + 标准 GDB Remote Serial Protocol
❖ 双轨调试系统架构分工src/rvdb/ & src/gdb/
对比维度 原生 rvdb 调试器 GDB Remote Stub
定位目标 零依赖、快速内省控制台 标准工具链与 IDE 接入
通信介质 终端 Stdin / Stdout (noline) TCP :1234 / Unix Socket
符号解析 内置 ELF SymTab 符号映射 客户端 GDB/DWARF 源码关联
硬件观察 CSR/时钟/物理MMIO直观读写 标准寄存器池与内存读写
生态兼容 独立原生 CLI & WASM 网页端 VS Code / CLion / GDB
-g 启动内置 rvdb；-G 启动标准 GDB Stub，互不冲突。
❖ 核心工程特性与实战价值
  • 自研轻量交互式 rvdb： 支持符号级断点（b main）、单步反汇编（si）、虚拟/物理地址翻译（trans）、执行流跟踪（ftrace），即使没有 GDB 工具链也能单步排查。
  • 工业级 GDB Remote Stub (0.7.10)： 完整实现 RISC-V 64 RSP 远程调试协议，支持软件断点（Z0）、硬件断点（Z1）、线程查询与寄存器组读写。
  • 内核级调试实操验证： 支持通过 VS Code 连入正运行 OpenSBI 与 Linux 内核的模拟器，下断点到 start_kernel 追踪内核启动全程。
❖ 脚本化自动化调试
支持 -S script.rvdb 预设命令自动化执行，在回归测试与 CI 中可实现无头静默单步验证与错误自动捕捉。
