❖ RVCPU 核心状态机src/isa/riscv/executor.rs
遵循紧凑内存布局，集成通用、特权、浮点与向量全系状态： 
#[repr(C)]
pub struct RVCPU {
    pub(crate) reg_file: RegFile, // 32通用寄存器
    pub(crate) pc: WordType,      // 程序计数器
    pub(super) memory: VirtAddrManager, // MMU
    pub(super) decoder: Decoder,  // 分级译码器
    pub(super) csr: CsrRegFile,   // 特权CSR堆
    pub(super) icache:
        Cache<DirectCache<DecodeInstr, 8192>>,
    pub(super) fpu: SoftFPU,      // 软浮点FPU
    pub(super) vector: Vector,    // RVV向量单元
}
内存紧凑布局 (#[repr(C)])： 消除结构体填充气泡，保证核心热点字段全量命中宿主 L1D Cache。
❖ get_exec_func 分派表机制编译期函数指针分派
弃用庞大的多重匹配分支，在 exec_mapping.rs 中将 RiscvInstr 直接映射为无状态函数指针： 
pub(in crate::isa::riscv) fn get_exec_func(
    instr: RiscvInstr,
) -> fn(RVInstrInfo, &mut RVCPU) -> Result<(), Exception> {
    match instr {
        RiscvInstr::ADD | RiscvInstr::ADDI =>
            exec_arith::<ExecAdd>,
        RiscvInstr::SUB => exec_arith::<ExecSub>,
        RiscvInstr::MUL => exec_arith::<ExecMulLow>,
        RiscvInstr::DIV => exec_arith::<ExecDivSigned>,
        RiscvInstr::VADD_VV => exec_vadd_vv,
        // 覆盖 1000+ 指令与泛型算子分派
    }
}
批处理执行 (Batch Step)： 每次迭代执行 1024 指令周期，集中处理中断判定与定时器同步，使解释执行吞吐最大化。
