◈ 核心亮点一：编译期元编程 —— 声明宏生成零开销译码

build.rs 自动解析 JSON 指令字典，通过声明宏 define_riscv_isa! 生成类型安全跳转表
❖ 构建期自动代码生成 (build.rs)build.rs → rvinstr_gen.rs
读取 data/instr_dict.json 自动化生成强类型枚举与静态描述表： 
// build.rs: 编译期解析 RISC-V 官方指令字典 JSON
let mut output = String::new();
output.push_str("define_riscv_isa!(RiscvInstr,\n");
parse_instr(&mut isa_dict, &ext_to_name, &json_path);
// 自动输出至 OUT_DIR/rvinstr_gen.rs
fs::write(&out_path, output).expect("Failed to write");
通过 include!(concat!(env!("OUT_DIR"), "/rvinstr_gen.rs")) 零成本载入。
❖ 声明宏 define_riscv_isa!
一个宏调用即可同时生成：RiscvInstr 枚举、isa_name() 反向反射、以及携带 mask/key 的不可变静态分派数组 &[RVInstrDesc]。
❖ 三大核心工程优势 (Single Source of Truth)
  • 单一真理源，消灭手工疏漏：直接消费 RISC-V 官方机器可读 JSON，摆脱手写几百条指令掩码与长位运算的繁重与人为 Bug。
  • 极致零运行时反序列化开销：代码在 cargo build 编译期一次性单向生成为原生 Rust 静态结构，运行时 0 开销。
  • 极简扩展自定义指令 (Custom ISA)： 支持通过 --features custom-instr 挂载外部自定义扩展 JSON，自动注入译码流水线，无需修改主工程核心代码。
❖ 前后端强类型契约绑定
前端译码输出 RiscvInstr 强类型枚举，后端 get_exec_func 编译器强制进行 match 完备性检查，漏写任何一条指令均会引发编译报错。
