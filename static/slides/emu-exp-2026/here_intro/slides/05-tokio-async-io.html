◈ 核心亮点三：Rust + Tokio —— 异步任务执行器架构

主频推进与宿主 I/O 彻底解耦：TaskSpawner 托管独立 Tokio 线程池并发处理外设任务
❖ CPU 纯计算与后台 Tokio Worker 流水线src/device/virtio/
主线程仅操作环形队列描述符与 mpsc channel，杜绝阻塞主频推进。
❖ CPU 纯计算与后台 Worker 协同机制
  • 主频零卡顿 (Zero CPU Stall)：模拟器主线程专心执行 RISC-V 指令批，大块磁盘 I/O 不会阻塞系统时钟，避免 Guest OS 出现时钟严重漂移。
  • 非阻塞通道快速投递：MMIO 寄存器写入触发 QueueNotify 时，仅将请求封包为 VirtIOBlockIoTask 推入 mpsc::Sender，耗时纳秒级。
  • 并发读写最大化吞吐：独立 Tokio 运行时利用 Host OS 异步 I/O 引擎（epoll/io_uring），充分释放宿主 SSD 读写带宽。
❖ 工业级 Rust 异步生命周期管理 (TaskSpawner)
通过 TaskSpawner 统一收拢管理所有外设异步任务，后台自动拉起独立 Tokio 运行时单线程/多线程池，解耦生命周期。
