◈ 模块一：Board 构建 —— 虚拟主板与系统拓扑

统一编排物理内存、MMIO 设备树拓扑与引导加载流程
❖ 虚拟主板结构体 (VirtBoard)src/board/virt.rs
全系统顶层容器，集聚 CPU、时钟源、物理内存与外设： 
pub struct VirtBoard {
    pub cpu: Box<RVCPU>,
    pub clock: VirtualClock,
    pub clint: DeviceHandle<Clint>,
    pub plic: DeviceHandle<PLIC>,
    pub device_arena: Box<DeviceArena>,
    pub status: BoardStatus,
}
统一单步与 step_batch(1024) 批处理，推进时钟与中断仲裁。
❖ 多端主板构建器 (Builder Pattern)
  • Native CLI: 完整支持 VirtIO Block、本地 ELF 文件加载、GDB TCP 远程监听。
  • WASM Target: 纯内存流驱动，无缝对接浏览器 WebAssembly 异步运行时。
❖ 物理地址空间映射 (Memory Map)QEMU 对标
基地址 (Base) 大小 设备 中断 / 职责
0x0010_0000 0x1000 PowerManager 软件关机 / 重启控制
0x0200_0000 0x1_0000 ACLINT/CLINT mtime/mtimecmp 时钟中断
0x0c00_0000 0x400_0000 PLIC 中断控制器 外部中断优先级仲裁
0x1000_0000 0x8 UART 16550A 控制台串口 (IRQ: 10)
0x1000_1000 0x1000 VirtIO MMIO 块设备磁盘存储 (IRQ: 1~8)
0x8000_0000 默认 2GB DRAM (Ram) ELF 段加载 / 内核挂载
ELFLoader 解析 ELF 段并注入物理内存，重定向 Entry PC。
