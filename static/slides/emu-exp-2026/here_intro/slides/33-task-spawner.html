◈ 模块五：异步运行时 —— TaskSpawner 与事件驱动 I/O

主核批处理执行与后台 Tokio 异步事件驱动解耦 · 避免磁盘与控制台阻塞主频
CPU 批处理与 I/O 解耦
模拟器主线程专心以 1024 周期内循环执行 RISC-V 指令，杜绝在 CPU 线程中发生磁盘或控制台阻塞调用。
TaskSpawner 异步线程池
基于 Tokio 运行时拉起常驻独立线程，外设通过 DeviceTask 注册异步 Future，在后台完成文件刷盘与网络读写。
Watch 广播通道优雅退出
使用 watch::channel。模拟器关机或收到中断信号时，广播 cancel 信号，安全 Flush 磁盘缓存，防止镜像损坏。
